Elas funcionam tanto como guias de procedimentos passo a passo para desenvolvedores humanos quanto como manuais de instrução para agentes de inteligência artificial (Antigravity, Claude Code, Hermes).

## 🤖 Como os Agentes de IA Utilizam estas Skills

1. **Progressive Disclosure**: O agente lê o frontmatter das skills para identificar qual procedimento aplicar para cada demanda.
2. **Deterministic Execution**: Cada skill fornece passos exatos, comandos de verificação e critérios de sucesso sem ambiguidade.
3. **Continuous Consistency**: Garante que qualquer nova nota adicionada no repositório siga a mesma identidade visual, formatação e estrutura bilíngue.
