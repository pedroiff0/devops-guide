# DevOps Standards — DevOps Guide

Instruções para boas práticas:

1. **Estrutura de Commits Convencionais:**
   - `<tipo>(<escopo opcional>): <descrição em imperativo>`
   - Exemplos de tipos: `feat`, `fix`, `docs`, `chore`, `ci`, `test`, `refactor`.
2. **Workflows Eficientes:**
   - Todo workflow do GitHub Actions deve incluir controle de concorrência e timeout máximo de 5 minutos.
